# Прогноз-Фрунзе

Веб-сайт закрытой лиги прогнозов матчей UEFA Champions League.

## Архитектура

- Next.js + TypeScript
- Supabase — авторизация и база данных
- Render — размещение сайта
- GitHub — исходный код и версии

## Правила начисления очков

- 3 очка — точный счёт
- 2 очка — правильная разница мячей
- 1 очко — правильный исход матча

Прогнозы участников должны оставаться скрытыми от других участников до наступления дедлайна/начала матча.
